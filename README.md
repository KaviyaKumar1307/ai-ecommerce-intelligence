# AURA Commerce - AI-Powered E-Commerce Intelligence System

## Live Servers
- Frontend: http://localhost:5173
- Backend API: http://localhost:5000
- AI Service: http://localhost:8000

## Quick Start

### Backend (zero-config SQLite)
`
cd backend
node server.js
`

### Frontend
`
cd frontend
npm run dev
`

### AI Service (optional)
`
cd ai-service
pip install -r requirements.txt
python main.py
`
